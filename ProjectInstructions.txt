# PROJECT: BatoDetailing - Full Car Detailing SaaS Platform

Build a complete production-ready web application for a car detailing business called **"BatoDetailing"**.

This is a full SaaS-style system with public website + user system + admin panel + booking + invoicing + reporting.

---

# TECH STACK

* Laravel 12
* PHP 8.4+
* PostgreSQL
* Blade Templates
* Tailwind CSS
* Alpine.js
* Laravel Auth (custom or Breeze/Jetstream)
* Laravel Policies & Gates
* Laravel Notifications
* Laravel Queues (mandatory)
* Laravel Mail
* Laravel Storage
* Laravel Localization (EN + SRB)
* Chart.js or ApexCharts

---

The system must support:

* Public marketing website
